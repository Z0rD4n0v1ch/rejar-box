# Rejar Box

Ремейки старых Java-игр с кнопочных телефонов: своя графика, своя музыка,
играется в браузере телефона и компьютера. Бесплатно.

## Игры

| Игра | Жанр | Играть |
|---|---|---|
| **Стальной Шершень** | шутер: вертолёт и пехота, 5 миссий | [steel-hornet/](steel-hornet/) |

## Как играть

Открой страницу игры в Chrome на телефоне. Управление — экранный джойстик
и кнопки, на компьютере — клавиатура (подробно в меню «Управление»).
Игра — один файл `index.html`, работает и без интернета, если скачать его.

## Структура

```
index.html            — витрина Rejar Box
steel-hornet/         — «Стальной Шершень»
  index.html          — игра целиком (код, спрайты, музыка внутри)
  cover.png           — обложка для витрины
sync.sh               — выложить изменения на GitHub
```
