# Rejar Box

Сборник ремейков старых Java-игр с кнопочных телефонов. Код, графика, музыка
и названия свои; оригинальные игры служат только образцом. Бесплатно,
открывается в браузере телефона и компьютера.

Играть: https://z0rd4n0v1ch.github.io/rejar-box/

## Структура

```
index.html            меню-полка с картриджами (строится из games/list.js), звук, «О проекте», установка
games/list.js         список игр: id, title, note, tags, cover, path, hidden, color, progress
shared/engine.js      общий движок для новых игр
games/template/       образец новой игры (скрыт в меню: hidden: true)
games/shershen/       «Стальной Шершень» — игра одним файлом index.html
  cover.png           картинка для карточки
  sw.js               офлайн-кэш только этой папки
manifest.webmanifest, sw.js, icon-*.png   установка меню на телефон, офлайн-кэш меню
originals/            оригинальные .jar для изучения (в репозиторий не попадают)
shared/tg.js          адаптер Telegram Mini App (шапка, «Назад», пауза звука, облачные сохранения)
sync.sh               отправка на GitHub
```

## Новая игра

1. Скопируй `games/template` в `games/<имя>`.
2. Добавь запись в `games/list.js` (поля описаны в начале файла).
3. Логика — в `game.js`, спрайты — в `sprites/` (фон `#FF00FF` станет прозрачным), музыка — в `music/`.

## Офлайн и кэш

Меню и каждая игра работают без интернета после первого открытия. Сервис-воркеры
всегда сначала спрашивают сервер, поэтому обновления видны сразу. Каждый `sw.js`
отвечает только за свою папку. Если поменял файлы меню, увеличь `VERSION` в корневом
`sw.js`; если поменял игру — в её `games/<игра>/sw.js`.

## Установка на телефон

Chrome → ⋮ → «Установить приложение» на странице меню или на странице игры.

## Публикация

После любых изменений: `./sync.sh` в Git Bash.

## Telegram

Rejar Box открывается как Mini App в боте. Сайт тот же (GitHub Pages), бот только открывает его.
Каждая страница подключает `telegram-web-app.js` и `shared/tg.js`; вне Telegram адаптер ничего не делает.
Прогресс игр (ключи с префиксами из `SYNC` в `shared/tg.js`) хранится и в облаке Telegram — новой игре
добавь туда свой префикс.

Игры с `data-full="1"` на телефоне открываются во весь экран. Кнопка «Поделиться» ведёт в бота, если в `shared/tg.js`
записан его юзернейм (`BOT`), иначе — на сайт.

Настройка бота в @BotFather: `/newbot` → `/mybots` → бот → Bot Settings → Configure Mini App →
Enable Mini App → адрес `https://z0rd4n0v1ch.github.io/rejar-box/`; там же Menu Button → тот же адрес, текст «Играть».
