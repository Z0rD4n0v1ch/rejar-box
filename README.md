# Rejar Box

Сборник ремейков старых Java-игр с кнопочных телефонов. Код, графика, музыка
и названия свои; оригинальные игры служат только образцом. Бесплатно и без рекламы,
открывается в браузере телефона и компьютера и в Telegram.

**Играть:** https://z0rd4n0v1ch.github.io/rejar-box/
**В Telegram:** https://t.me/rejarbox_app

## Игры

| Игра | Что это |
|---|---|
| [**Борт 11**](games/shershen/) | шутер: вертолёт и пехота, 11 миссий, 3 сложности, финал кампании |
| [**Петля прилива**](games/petlya/) | мистическое приключение на острове: выжившие с парома, племя ману и петля времени между 2026 и 2056 годом; два акта, выборы, три концовки, тайники и достижения |
| [**Ночная стража**](games/strazha/) | платформер о Петербурге 1905–1917 годов: крыши, скрытность и тайное общество «Циферблат»; ранняя версия — 1 миссия из 15 |

## Как играть

- Управление на телефоне — касаниями, на компьютере — клавиатурой.
- Прогресс сохраняется сам; в Telegram он хранится в облаке и одинаков на всех устройствах.
- Игры работают без интернета после первого открытия.
- Можно установить на телефон: Chrome → ⋮ → «Установить приложение».
