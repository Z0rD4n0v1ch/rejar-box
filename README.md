# Rejar Box

Ремейки старых Java-игр с кнопочных телефонов: своя графика, своя музыка,
играется в браузере телефона и компьютера. Бесплатно.

## Игры

| Игра | Жанр | Играть |
|---|---|---|
| **Стальной Шершень** | шутер: вертолёт и пехота, 5 миссий | [steel-hornet/](steel-hornet/) |

## Как играть

Открой страницу игры в Chrome на телефоне. Управление — экранный джойстик
и кнопки, на компьютере — клавиатура (подробно в меню «Управление»).
Витрину и каждую игру можно установить на телефон как приложение:
Chrome → ⋮ → «Установить приложение» (или кнопка «Установить» на странице).
После первого открытия всё работает без интернета.

## Структура

```
index.html            — витрина Rejar Box (каталог игр — массив GAMES в конце файла)
manifest.webmanifest  — описание приложения «Rejar Box» для установки
sw.js                 — офлайн-кэш витрины и всех игр (новую игру впиши в FILES)
icon-192.png, icon-512.png — иконка коллекции
steel-hornet/         — «Стальной Шершень»
  index.html          — игра целиком (код, спрайты, музыка внутри)
  cover.png           — обложка для витрины
  manifest.webmanifest, sw.js, icon-*.png — установка игры отдельным приложением
sync.sh               — выложить изменения на GitHub
```

## Как добавить новую игру

1. Папка `имя-игры/` с `index.html` и `cover.png`.
2. Запись в массив `GAMES` в `index.html` витрины (название, описание, как читать рекорды).
3. Файлы игры — в список `FILES` в `sw.js`, и поменять `VERSION`.
