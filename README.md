# Rejar Box

Сборник ремейков старых Java-игр для телефонов. Код, графика и музыка свои, оригинальные игры служат только образцом. Всё бесплатно и открывается в браузере.

Играть: https://z0rd4n0v1ch.github.io/rejar-box/

## Игры

| Игра | Что это |
|---|---|
| [Стальной Шершень](https://z0rd4n0v1ch.github.io/rejar-box/steel-hornet/) | вертолёт и пехота, 5 миссий, 3 сложности |
| Шаблон | образец для новых игр |

## Установка на телефон

Открой https://z0rd4n0v1ch.github.io/rejar-box/ в Chrome и нажми «Установить»
(или ⋮ → «Установить приложение»). После первого открытия всё работает без интернета.
«Стальной Шершень» можно установить и отдельной иконкой со своей страницы.

## Структура

```
index.html        меню со списком игр
shared/engine.js  общий движок: экран, управление, спрайты, звук, сохранения
games/list.js     список игр в меню
games/<игра>/     index.html, game.js, sprites/, music/
steel-hornet/     «Стальной Шершень» — одним файлом index.html (свой движок внутри)
manifest.webmanifest, sw.js, icon-*.png — установка меню на телефон и офлайн-кэш
originals/        оригинальные .jar для изучения (в репозиторий не попадают)
sync.sh           отправка на GitHub
```

## Новая игра

1. Скопируй `games/template` в `games/<имя-игры>`.
2. Добавь строку в `games/list.js`.
   Чтобы игра работала без интернета, впиши её файлы в `FILES` в `sw.js` и поменяй там `VERSION`.
3. Пиши логику в `game.js`, спрайты клади в `sprites/`, музыку в `music/`.

Спрайты делай на фоне `#FF00FF`: движок сам сделает его прозрачным.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | стрелки, WASD, 2/4/6/8 | крестовина |
| Огонь | пробел, Enter, J, 5 | A |
| Доп. действие | K, Shift, 0 | B |
| Выход в меню | Esc, Backspace | Меню |

## Запуск на компьютере

Двойной клик по `index.html` работает, но прозрачный фон спрайтов так не включится (ограничение браузера). Лучше запустить локальный сервер в папке проекта:

```
python -m http.server 8000
```

и открыть http://localhost:8000

## Публикация

1. Создай на GitHub пустой репозиторий `rejar-box` (без README).
2. Запусти `./sync.sh` в Git Bash.
3. В настройках репозитория: Settings → Pages → Branch: `main`, папка `/ (root)` → Save.

Дальше после любых изменений достаточно `./sync.sh`.
